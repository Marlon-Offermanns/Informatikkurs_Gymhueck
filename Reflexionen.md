## Reflexion Kapitel 1

- Git ist die Dateiverwaltungssoftware, während Github die Webseite ist, wo die Daten abgespeichert werden.
- Die Versionsvertaltung ist sinvoll, da man, falls man was falsch gemacht hat, zur letzten Version zurückspringen kann.
- Lokal heißt auf dem persönlichem Computer, online heißt im Internet verfügbar.


## Reflexion Kapitel 2

- Ein Repository ist ein Ordner, der durch Git verwaltet wird.
- Zuerst käme das Kursmaterial, dann Git und GitHub, dann Projekte und dann Bilder.
- Der Projektname sollte klar sein, damit man die Datei leichter finden kann.
- GitHub dient als Backup.


## Reflexion Kapitel 3

- Die Änderung einer Datei wird ausgewählt für den nächsten Commit.
- add ist fast dasselbe, weil der git-Befehl alle Änderungnen auswählt, ähnlich wie stage.
- Wenn man erkennen kann, was geändert wurde.
